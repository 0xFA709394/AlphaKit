# 08 · 部署指南

## 一、Web 服务(Nginx + FPM)

```nginx
server {
    listen 80;
    server_name example.com;
    root /var/www/AlphaKit/public;      # 指向 public!
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;   # 前端控制器
    }

    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    # 静态资源缓存
    location ~* \.(css|js|png|jpg|svg|woff2)$ {
        expires 7d;
    }
}
```

Apache(.htaccess 放 `public/`):

```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>
```

## 二、目录权限

```bash
chown -R www-data:www-data storage
chmod -R 775 storage
```

## 三、环境切换

```bash
cp .env.example .env
vim .env        # 关键项:
#   APP_ENV=production
#   APP_DEBUG=false          # 生产必须关闭!
#   DB_CONNECTION=mysql ...
#   JWT_SECRET=<php bin/alphakit key:generate --show>
php bin/alphakit migrate
```

## 四、队列常驻进程(supervisor)

```ini
; /etc/supervisor/conf.d/alphakit-worker.conf
[program:alphakit-worker]
command=php /var/www/AlphaKit/bin/alphakit queue:work
directory=/var/www/AlphaKit
autostart=true
autorestart=true
stopasgroup=true
user=www-data
stdout_logfile=/var/www/AlphaKit/storage/logs/worker.log
redirect_stderr=true
```

```bash
supervisorctl reread && supervisorctl update && supervisorctl start alphakit-worker
```

> 多队列:`command=php bin/alphakit queue:work --queue=high,default`,可配多个进程。

## 五、定时任务(唯一 cron)

```bash
crontab -e -u www-data
* * * * * cd /var/www/AlphaKit && php bin/alphakit schedule:run >> storage/logs/schedule.log 2>&1
```

## 六、安全清单

- [ ] `APP_DEBUG=false`(调试页会泄露路径与堆栈)
- [ ] `JWT_SECRET` 强随机且不入库
- [ ] HTTPS 强制(HTTP 跳转 + HSTS)
- [ ] 生产隐藏 `.env`/`storage/`(Nginx 已因 root=public 天然隔离)
- [ ] SQL 全部参数绑定(框架 QueryBuilder/Model 默认绑定)
- [ ] 输出统一 `e()` 转义防 XSS;JSON 接口 `json_encode` 天生安全
- [ ] 敏感接口加 `auth` + `throttle`
- [ ] 上传文件校验扩展名/MIME 并重命名,存放 public 外

## 七、性能建议

- 热点数据接 `cache_store()->getOrSet()`(300s TTL 起步)
- 大列表分页(`paginate`)而非 `all()`
- 耗时操作一律 `dispatch()` 进队列
- MySQL 生产环境:迁移建索引(`$table->index(...)`)
- 上线前 `php bin/alphakit routes` 审计路由与中间件覆盖

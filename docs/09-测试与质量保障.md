# 09 · 测试与质量保障

AlphaKit 经过九轮实证式代码审查（探针复现 → 修复 → 复验 → 固化），累计修复 33 处缺陷，并把全部结论固化为 **137 项可重复执行的测试断言**。本文档说明如何复现质量保障体系，以及框架已建立的关键不变量。

## 三、框架不变量(审查建立并受测试保障)

**数据层**
- 查询构造器 / Model 全部参数绑定,无字符串拼接 SQL
- 无 WHERE 的全表 `UPDATE` / `DELETE` 直接抛异常
- `whereIn` 空集恒假、`whereNotIn` 空集恒真(不生成非法 `IN ()`)
- 聚合(`count/sum/avg`)自动剥离 `ORDER BY / LIMIT / OFFSET`
- `upsert` 按方言生成:sqlite `ON CONFLICT` / mysql `ON DUPLICATE KEY UPDATE`
- 分页 `last_page` 下限 1;`chunk` 全覆盖无重复
- `Schema` 列名按方言转义(MySQL 默认模式双引号是字符串字面量)
- 事务支持嵌套(内层自动 `SAVEPOINT`)
- Model 脏字段严格比较;`__get` 魔术访问与 `toArray()` 统一应用 casts
- `timestamps=false` 不写时间戳

**路由 / 中间件**
- 可选参数 `{x?}` 连同前导斜杠整体可选;参数支持正则约束
- 404 / 405 区分;`resource` 支持 `only` 裁剪
- 中间件参数按 `handle()` 类型提示自动转换(`'060'` → int)
- 容器循环依赖检测(不再栈溢出)

**安全**
- php -S 路由脚本 `realpath` 限定静态文件于 `public/` 内(防 `../` 穿越)
- `Response::withHeader` / 构造器统一剥离 CRLF(防头注入)
- Session Cookie 携带 `HttpOnly + SameSite=Lax`(`session.secure` 可开)
- JWT 支持验签 + exp/nbf 校验 + alg 白名单(alg=none 拦截)
- 生产环境弱 JWT 密钥 boot 时写 `security-*.log` 告警
- 注册邮箱唯一约束竞态由数据库约束兜底,返回 422 而非 500
- `E_DEPRECATED` 不升级为异常(避免误伤第三方代码);真实错误仍升级

**队列 / 调度**
- `pop` 原子抢占,2 进程并发消费无重复无丢失
- 类缺失的历史任务按坏任务删除,常驻 worker 不崩
- 重试语义:`tries` 耗尽 → `failed_jobs` 记录 + `failed()` 回调
- 超时预留(>60s)自动回收重派;延迟任务不被提前消费
- 迁移器连接路由:迁移体 DDL 与记账始终同连接;类名冲突跨文件拦截、同文件复用放行

**错误处理**
- 非法 UTF-8 JSON 统一替换为 U+FFFD,响应体永不为空
- `download` 缺失文件抛 404 而非空下载
- HEAD 请求体由 SAPI 正确抑制;畸形 JSON 优雅降级 422

## 四、审查方法论

每轮遵循同一闭环,结论均可复现:

```
枚举目标(模块/维度/分支)
  → 可执行探针复现疑点(不凭直觉改代码)
  → 修复
  → 探针复验
  → 断言固化进 unit_test / smoke_test / mysql_test
```

历轮:R1 核心逻辑(13 修复) → R2 运行时状态(4) → R3 并发(3) → R4 攻击面(5) → R5 零覆盖路径(1) → R6 HTTP 协议(2) → R7 隔离性(2) → R8 MySQL 方言(3) → R9 分支全覆盖(0)。

缺陷密度 13 → 4 → 3 → 5 → 1 → 2 → 2 → 3 → **0**,已收敛。

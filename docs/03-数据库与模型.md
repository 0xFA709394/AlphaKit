# 03 · 数据库与模型

## 连接配置

`config/database.php` + `.env`,默认 SQLite 零配置:

```dotenv
DB_CONNECTION=sqlite          # 切换 mysql 时改为下方配置
# DB_CONNECTION=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=alphakit
# DB_USERNAME=root
# DB_PASSWORD=secret
```

框架所有 SQL 方言差异(标识符引号/建表语法)已自动适配 sqlite / mysql。

## 查询构造器

```php
use AlphaKit\Database\QueryBuilder;

$rows = QueryBuilder::table('tasks')
    ->select('id', 'title', 'done')
    ->where('user_id', '=', 1)
    ->whereLike('title', '%周报%')
    ->where('created_at', '>=', '2026-01-01')
    ->whereNull('deleted_at')
    ->whereIn('status', [1, 2, 3])
    ->whereBetween('score', 60, 100)
    ->whereGroup(fn ($q) => $q->where('a', 1)->orWhere('b', 2))  // 嵌套 OR 组
    ->orderBy('id', 'desc')
    ->limit(10)->offset(20)
    ->get();                       // 多行(数组)

QueryBuilder::table('tasks')->where('id', 1)->first();   // 单行
QueryBuilder::table('tasks')->count();                    // 计数
QueryBuilder::table('tasks')->where('done', 1)->sum('score');
QueryBuilder::table('tasks')->paginate(15, $page);        // 分页(见下)

// 写操作(UPDATE/DELETE 必须带 where,防全表误伤)
QueryBuilder::table('tasks')->insert(['title' => 'x', 'user_id' => 1]);   // 返回自增 ID
QueryBuilder::table('users')->insertMany([[...], [...]]);                  // 批量
QueryBuilder::table('tasks')->where('id', 1)->update(['done' => 1]);
QueryBuilder::table('tasks')->where('id', 1)->delete();
QueryBuilder::table('counters')->where('id', 1)->increment('hits');        // 原子自增
QueryBuilder::table('configs')->upsert($data, ['key']);                    // 存在即更新
```

分页返回结构:

```json
{ "data": [...], "total": 100, "page": 1, "per_page": 15, "last_page": 7 }
```

## Model(Active Record)

```php
final class Task extends Model
{
    protected string $table = 'tasks';
    protected array $hidden = ['password'];        // 序列化隐藏
    protected array $casts = [                     // 类型转换
        'done' => 'bool',
        'tags' => 'json',
        'score' => 'float',
    ];
}
```

```php
// 查询
Task::find(1);                       // 主键查;findOrFail(1) 不存在抛 404
Task::all();
Task::where('done', 1)->orderBy('id', 'desc')->limit(10)->get();
Task::count();

// 写入
$task = Task::create(['title' => '写周报', 'user_id' => 1]);  // 创建并保存
$task->title = '改题目'; $task->save();                        // 更新
$task->update(['done' => true]);                               // 批量更新
$task->delete();                                               // 删除

// 转数组:自动应用 hidden/casts;JSON 序列化同样生效
$task->toArray();
```

> 时间戳:模型默认维护 `created_at / updated_at`,设 `protected bool $timestamps = false;` 关闭。

## 关联

```php
class User extends Model
{
    public function tasks(): array
    {
        return $this->hasMany(Task::class);         // 外键约定:user_id
    }
}

class Task extends Model
{
    public function user(): ?User
    {
        return $this->belongsTo(User::class);       // Task.user_id -> User.id
    }
}

// 使用(外键/主键不符合约定时传第二、三参数)
$user = User::find(1);
$user->tasks();                                     // Task[] 数组
$task = Task::find(1);
$task->user()->email;                               // 所属用户
$task->user;                                        // 魔术属性 = 缓存式调用
```

`toArray()` 会自动递归包含**已加载**的关联(手动赋值 `$task->user = $u` 后)。

## 事务

```php
use AlphaKit\Database\Connection;

app(Connection::class)->transaction(function (Connection $conn) {
    $conn->execute('UPDATE accounts SET balance = balance - 100 WHERE id = ?', [1]);
    $conn->execute('UPDATE accounts SET balance = balance + 100 WHERE id = ?', [2]);
    // 闭包抛异常自动回滚,正常返回自动提交
});
```

## 迁移

生成并编写:

```bash
php bin/alphakit make:migration create_posts_table --table=posts
php bin/alphakit make:model Post --migration        # 模型+迁移一步到位
```

`database/migrations/20260101_000001_create_posts_table.php`:

```php
use AlphaKit\Database\Migration;
use AlphaKit\Database\Schema\{Blueprint, Schema};

final class CreatePostsTable extends Migration
{
    public function up(): void
    {
        Schema::create('posts', function (Blueprint $table) {
            $table->id();                          // 自增主键
            $table->string('title');               // VARCHAR/TEXT
            $table->string('slug')->unique();      // 唯一约束
            $table->text('content')->nullable();
            $table->boolean('published')->default(0);
            $table->integer('views')->default(0);
            $table->json('meta')->nullable();
            $table->datetime('published_at')->nullable();
            $table->timestamps();                  // created_at + updated_at
            $table->index('slug');
        });
    }

    public function down(): void
    {
        Schema::dropIfExists('posts');
    }
}
```

执行:

```bash
php bin/alphakit migrate               # 执行
php bin/alphakit migrate:rollback      # 回滚最后一批
php bin/alphakit migrate:reset         # 全部回滚
php bin/alphakit migrate:status        # 状态
php bin/alphakit db:seed               # 种子数据(database/seeders.php)
```

Blueprint 列类型速查:

| 方法 | sqlite | mysql |
|------|--------|-------|
| `id()` | INTEGER PK 自增 | BIGINT UNSIGNED PK 自增 |
| `integer / bigInteger` | INTEGER | INT |
| `string(n)` | TEXT | VARCHAR(n) |
| `text` | TEXT | TEXT |
| `boolean` | INTEGER(0/1) | TINYINT(1) |
| `float / decimal` | REAL | REAL/DECIMAL |
| `datetime / date` | TEXT | DATETIME/DATE |
| `json` | TEXT | JSON |

修饰链:`->nullable()` `->default($v)` `->unique()`;`$table->softDeletes()` 加 `deleted_at`。

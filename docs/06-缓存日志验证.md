# 06 · 缓存 / 日志 / 校验 / Session / 视图

## 缓存

驱动:`file`(默认)/ `redis`(需 ext-redis,缺失自动降级 file)/ `array`(单请求内存,测试用)。
切换:`.env CACHE_DRIVER=redis`。

```php
$cache = cache_store();                  // 默认驱动
$cache = cache_store('redis');           // 指定驱动

// 基础
$cache->set('key', $value, 3600);        // TTL 秒;null = 永久
$value = $cache->get('key', $default);
$cache->has('key'); $cache->delete('key'); $cache->clear();

// 组合(最常用)
$users = $cache->getOrSet('hot_users', 300, fn () => User::all());
// 等价 Laravel remember:未命中执行闭包并缓存 5 分钟

$count = $cache->increment('pv');        // 原子计数
$value = $cache->pull('key');            // 读取并删除(一次性令牌)
```

**典型场景**:接口数据缓存、防重放令牌、限流计数(见 ThrottleRequests 中间件)、报表预热。

## 日志

按通道分文件,按天切割,存 `storage/logs/<channel>-YYYY-MM-DD.log`:

```php
logger()->info('订单创建', ['order_id' => 123]);
logger('payment')->warning('金额异常', ['amount' => -1]);
logger()->error('失败', ['exception' => (string) $e]);
// 级别:debug info notice warning error critical alert emergency
// 最低级别 .env LOG_LEVEL 控制,默认 debug 全记录
```

未捕获异常与队列失败自动写日志(通道 `app`)。

## 参数校验

```php
$v = validator($request->all(), [
    'name'     => 'required|string|max:50',
    'email'    => 'required|email|unique:users,email',      // 数据库唯一
    'password' => 'required|string|min:6|confirmed',        // 需带 password_confirmation
    'age'      => 'nullable|integer|between:1,150',
    'role'     => 'required|in:admin,editor,user',
    'phone'    => 'nullable|mobile',                        // 中国手机号
    'slug'     => 'alpha_dash',
    'url'      => 'nullable|url',
    'code'     => 'regex:/^\d{6}$/',
    'user_id'  => 'required|integer|exists:users,id',       // 存在性
]);

if ($v->fails()) {
    $errors = $v->errors();        // ['email' => ['email 已被占用'], ...]
    return Response::fail($v->firstError(), 422, 422, $errors);
}
$data = $v->validated();          // 仅含规则内字段
```

控制器里一步到位(`Controller::validate`,失败自动 422 JSON):

```php
$data = $this->validate($request, ['title' => 'required|string|max:200']);
```

> `nullable`:字段为空跳过其余规则;`required`:空值报错。支持 `a.b` 点号校验嵌套 JSON。

## Session

文件驱动,`session` 中间件启动(Web 路由组已配置):

```php
/** @var AlphaKit\Core\Session $session */
$session = app(AlphaKit\Core\Session::class);

$session->put('user_id', 1);
$session->get('user_id');
$session->has('user_id');  $session->forget('user_id');  $session->flush();

// Flash:写入后仅在下一次请求可见(一次性提示)
$session->flash('message', '创建成功');
$session->getFlash('message');

$session->regenerate();    // 登录后重建 ID(防会话固定)
```

配置 `config/session.php`:cookie 名 / 有效期。

## 视图

原生 PHP 模板,目录 `app/views/`,自动转义用 `e()`:

```php
return view('tasks/index', ['tasks' => $tasks]);
// 或控制器内: return $this->view('tasks/index', $data);
```

**布局继承**(`app/views/tasks/index.php`):

```php
<?php $this->extend('layouts/app'); ?>

<?php $this->start('title'); ?>任务列表<?php $this->end(); ?>

<?php $this->start('content'); ?>
    <h1>任务列表</h1>
    <?php foreach ($tasks as $task): ?>
        <div><?= e($task['title']) ?></div>
    <?php endforeach; ?>
<?php $this->end(); ?>
```

**布局**(`app/views/layouts/app.php`):

```php
<title><?= $this->section('title', '默认标题') ?></title>
<body>
    <?= $this->section('content') ?>
</body>
```

视图内可用 `$this->insert('partials/header', $data)` 引入子视图。

## 事件系统(观察者)

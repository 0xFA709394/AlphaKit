# 04 · 队列与调度

## 一、队列(异步任务)

**适用**:发邮件、短信、生成报表、第三方 API 调用等耗时操作 —— 接口立即返回,任务后台执行。

默认 `database` 驱动(jobs 表,自动建表,零配置);测试可切 `.env QUEUE_DRIVER=sync`(同步执行)。

### 1. 创建任务

```bash
php bin/alphakit make:job SendWelcomeEmail
```

```php
final class SendWelcomeEmail
{
    public int $tries = 3;          // 最大尝试次数(失败自动重试)
    public int $retryAfter = 10;    // 重试延迟(秒)

    public function __construct(protected array $payload = []) {}

    public function handle(): void
    {
        // 异步业务逻辑;公共属性若有类型提示,容器自动注入服务
        logger('mail')->info('发送邮件', $this->payload);
    }

    public function failed(Throwable $e): void   // 可选:最终失败回调
    {
        logger('mail')->error('邮件发送最终失败', ['error' => $e->getMessage()]);
    }
}
```

### 2. 派发

```php
// dispatch() 为全局助手函数
dispatch(new SendWelcomeEmail(['user_id' => 1, 'email' => 'a@b.c']));

// 延迟 60 秒执行
app(AlphaKit\Queue\QueueManager::class)->later(60, new SendWelcomeEmail([...]));
```

### 3. 消费

```bash
php bin/alphakit queue:work                     # 常驻(supervisor 托管,见 08-部署)
php bin/alphakit queue:work --once              # 处理一条退出
php bin/alphakit queue:work --max-jobs=100      # 批量清空模式(处理到 N 条或队列空退出,适合 cron)
php bin/alphakit queue:work --queue=high        # 多队列区分优先级
php bin/alphakit queue:failed                   # 查看失败任务
```

**重试机制**:任务抛异常且 `attempts < $tries` → 延迟 `retryAfter` 秒重新入队;超过次数 → 记入 `failed_jobs` 表并触发 `failed()` 回调。

**多队列优先级**:

```php
dispatch(...);                        // 默认队列 default
app(QueueManager::class)->push($job, 'high');
```

```bash
php bin/alphakit queue:work --queue=high,default   # 先消费 high
```

## 二、调度(定时任务)

注册表 `app/schedule.php`(文件内 `$schedule` 已注入):

```php
use AlphaKit\Schedule\Scheduler;

// 闭包任务
$schedule->call(fn () => User::where('expired', 1)->delete())
    ->everyFiveMinutes()->name('清理过期用户');

// 命令任务(子进程执行 CLI 命令)
$schedule->command('task:stats')->dailyAt('09:00')->name('每日统计');

// 标准 cron 表达式(分 时 日 月 周)
$schedule->call(fn () => backup())->cron('30 2 * * *');
```

频率速查:

| 方法 | 表达式 |
|------|--------|
| `everyMinute() / everyTwoMinutes()` | `* * * * *` / `*/2 * * * *` |
| `everyFiveMinutes() / everyTenMinutes() / everyThirtyMinutes()` | `*/5` `*/10` `*/30` |
| `hourly() / hourlyAt(30)` | `0 * * * *` / `30 * * * *` |
| `daily() / dailyAt('02:30')` | `0 0 * * *` / `30 2 * * *` |
| `weekly() / weeklyOn(1, '09:00')` | `0 0 * * 0` |
| `monthly()` | `0 0 1 * *` |

### 调试

```bash
php bin/alphakit schedule:list      # 查看全部任务、cron 表达式、当前是否到期
php bin/alphakit schedule:run       # 手动执行到期任务
```

### 生产部署(唯一一条系统 cron)

```bash
crontab -e
# 添加:
* * * * * cd /path/to/AlphaKit && php bin/alphakit schedule:run >> storage/logs/schedule.log 2>&1
```

调度器每分钟被唤醒,自动判断哪些任务到期并执行 —— 新增周期任务**无需改 crontab**。

## 推荐组合模式

```
API 请求 ──dispatch()──▶ 队列(jobs 表)
                            │
              queue:work 常驻进程消费
                            │
              耗时逻辑执行(可重试/失败兜底)

schedule:run(每分钟) ──▶ 周期任务:数据同步 / 清理 / 报表
                            │
                 复杂耗时逻辑同样 dispatch() 进队列
```

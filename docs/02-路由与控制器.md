# 02 · 路由与控制器

## 路由定义

路由文件:`routes/web.php`(页面)与 `routes/api.php`(接口),均返回闭包并注入 `$router`:

```php
use AlphaKit\Core\Router;

return function (Router $router): void {
    // 闭包处理器
    $router->get('/ping', fn () => ['pong' => true]);

    // 控制器处理器
    $router->get('/users/{id}', [UserController::class, 'show']);

    // 路由参数约束(正则)
    $router->get('/posts/{id:\d+}', [PostController::class, 'show']);

    // 可选参数
    $router->get('/news/{page?}', [NewsController::class, 'index']);
};
```

支持的谓词:`get / post / put / patch / delete / any`。

## 路由分组

分组支持嵌套,`prefix` 与 `middleware` 自动叠加:

```php
$router->group(['prefix' => '/api'], function (Router $router): void {
    $router->group(['middleware' => ['auth']], function (Router $router): void {
        // /api/tasks - auth 中间件保护
        $router->resource('/tasks', TaskController::class);
    });
});
```

## 资源路由(RESTful 一键生成)

```php
$router->resource('/tasks', TaskController::class);
// 等价于:
// GET    /tasks          -> index    列表
// POST   /tasks          -> store    创建
// GET    /tasks/{id}     -> show     详情
// PUT    /tasks/{id}     -> update   更新(PATCH 同)
// DELETE /tasks/{id}     -> destroy  删除

// 只暴露部分方法
$router->resource('/tasks', TaskController::class, ['index', 'show']);
```

生成对应控制器骨架:

```bash
php bin/alphakit make:controller TaskController --api --resource
```

## 中间件

实现 `MiddlewareInterface`(洋葱模型,`$next` 之后是后置逻辑):

```php
use AlphaKit\Core\Middleware\MiddlewareInterface;
use AlphaKit\Core\{Request, Response};

final class AuditLog implements MiddlewareInterface
{
    public function handle(Request $request, callable $next): Response
    {
        $start = microtime(true);
        $response = $next($request);                 // 前置 → 后置分界

        logger('audit')->info('请求完成', [
            'path' => $request->path(),
            'status' => $response->status(),
            'ms' => round((microtime(true) - $start) * 1000),
        ]);
        return $response;
    }
}
```

注册别名(`config/app.php`)后在路由上按别名使用:

```php
'middleware_aliases' => [
    'auth'    => \App\Middleware\Authenticate::class,
    'throttle'=> \App\Middleware\ThrottleRequests::class,
],

// 使用(支持参数,冒号分隔,逗号分隔多个):
$router->get('/sms/send', [SmsController::class, 'send'])->middleware('throttle:1,60');
```

全局中间件:`config/app.php` 的 `global_middleware`(所有请求生效)。

内置中间件:

| 别名 | 说明 |
|------|------|
| `session` | 框架内置 `StartSession`,Web 分组使用 |
| `auth` | 演示应用实现,JWT 校验并注入 `$request->user` |
| `throttle:60,60` | 演示应用实现,60 秒 60 次限流(缓存计数) |

## 控制器

继承 `Controller` 基类,构造函数支持依赖注入,方法注入 `Request`:

```php
final class TaskController extends Controller
{
    public function __construct(protected AuthManager $auth) {}

    public function index(Request $request): Response
    {
        $data = $this->validate($request, [        // 校验失败自动 422
            'title' => 'required|string|max:200',
        ]);

        return $this->ok($result);                 // {"code":0,"message":"ok","data":...}
        return $this->fail('出错', 1, 400);         // {"code":1,"message":"出错"}
    }
}
```

路由参数通过 `$request->params['id']` 读取。

## 响应

```php
Response::json($data, 200);               // JSON
Response::html($content);                 // HTML
Response::text($content);                 // 纯文本
Response::redirect('/login');             // 302
Response::download($file, '报表.xlsx');    // 下载
Response::ok($data, '创建成功')->withStatus(201);
Response::fail('参数错误', 1, 422, $errors);
$response->withHeader('X-Custom', 'v1');
```

控制器返回数组/标量会自动转 JSON;返回 `Response` 对象原样输出。

## 错误处理

- 抛 `HttpException` / `abort(403, '无权访问')` → 对应状态码
- API 路径(`/api/*` 或 Accept: json)自动 JSON 错误;否则渲染错误页
- `APP_DEBUG=true` 时显示堆栈;生产环境 500 隐藏细节并写日志
- 404 / 405 由路由器自动区分

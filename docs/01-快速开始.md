# 01 · 快速开始

## 环境要求

| 组件 | 要求 | 说明 |
|------|------|------|
| PHP | ≥ 7.4 | 需要 `pdo_sqlite` 扩展(默认数据库) |
| 可选 | `pdo_mysql` | 使用 MySQL 时 |
| 可选 | `ext-redis` | 使用 Redis 缓存/队列时(缺失自动降级文件缓存) |
| 可选 | `ext-curl` | 使用 HTTP 客户端 |

确认环境:

```bash
php -v
php -m | grep -E 'pdo_sqlite|curl'
```

> macOS 无 PHP 时可 `brew install php`;框架对 PHP 8.x 完全兼容。

## 安装与启动

框架**零 Composer 依赖**,克隆即用:

```bash
cd AlphaKit

# 1. 复制环境配置(或直接使用自带 .env)
cp .env.example .env

# 2. 生成 JWT 密钥
php bin/alphakit key:generate

# 3. 启动开发服务器
php bin/alphakit serve              # 默认 http://127.0.0.1:8000
php bin/alphakit serve --port=9000  # 自定义端口
```

初始化数据库(SQLite,自动创建文件):

```bash
php bin/alphakit migrate            # 建表
php bin/alphakit db:seed            # 种子数据(演示账号 demo@alphakit.dev / demo1234)
```

## 请求生命周期

```
浏览器/curl
   │
   ▼
public/index.php            ← 所有 HTTP 请求唯一入口
   │ require alphakit/bootstrap.php(自动加载 + .env + 助手函数)
   ▼
Application::getInstance() ← 引导:配置 → 服务提供者 → 路由文件
   │
   ▼
Router::match(method, path) ← 匹配路由(404 / 405 检测)
   │
   ▼
中间件管道(全局 → 路由组 → 路由)     ← 洋葱模型
   │
   ▼
控制器方法(Request 注入)
   │ 返回 Response / 数组(自动转 JSON)
   ▼
Response::send()            ← 输出响应
```

CLI 请求走 `bin/alphakit` → `ConsoleApplication::run($argv)` → 命令分发。

## 配置文件

所有配置在 `config/` 目录,通过 `config()` 助手读取(点号语法):

```php
config('app.name');              // "AlphaKit"
config('database.default');      // "sqlite"
config('cache.stores.redis.host', '127.0.0.1');
```

`.env` 文件存放环境差异配置(生产/开发分离),通过 `env()` 读取:

```php
env('APP_DEBUG', false);         // 支持布尔/空值语义: true/false/null/empty
```

`config/*.php` 中引用 `env()`,运行时用 `config()` —— 这是推荐分层。

## 常用助手函数

```php
app(Service::class)     // 从容器解析服务
config('app.name')      // 读配置
env('DB_HOST')          // 读环境变量
base_path('app/')       // 项目根目录
storage_path('logs')    // storage 目录
view('welcome', $data)  // 渲染视图
response() / json_response($data)
validator($data, $rules)
dispatch(new SomeJob())  // 派发队列任务
cache_store()->get('k')
logger()->info('...')
abort(404, '未找到')
e($html)                // HTML 转义
```
